# FORMA — Digital projects by Nir

Static, Hebrew portfolio with individual project pages, responsive project gallery and a Three.js product tour.

Run locally: `node serve.cjs`, then open http://127.0.0.1:4317/.

Projects: NOYA, Blue Bay Wash, NEXORA, Web Control Room, Nahariya 1990, ARIEL.

Contact submission is intentionally disabled. ARIEL is presented as a development version. Concept artwork is labelled separately from original project screenshots.
